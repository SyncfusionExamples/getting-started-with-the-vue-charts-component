# getting-started-with-the-vue-charts-component
A quick start Vue project that shows how to add [Vue Charts](https://www.syncfusion.com/vue-components/vue-charts?utm_source=github&utm_medium=listing&utm_campaign=vue-charts-github-samples) component to a Vue project using the Vue CLI. This project also includes a code snippet to populate data and set series types in charts and add legends, data labels, and tooltips.
